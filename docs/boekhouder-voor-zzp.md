# Boekhouder voor zzp

Een zzp'er wil vooral dat de boekhouding klopt zonder dat administratie het werk overneemt. Winstwaker richt zich op Nederlandse zzp'ers die documenten, btw en cijfers overzichtelijk geregeld willen hebben.

Winstwaker combineert software voor snelheid met een boekhouder voor zekerheid.

Website: https://www.winstwaker.nl/
